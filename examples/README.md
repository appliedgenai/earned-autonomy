# Design examples

These synthetic specifications support the [reference design](../reference-design.md).

- [Action contract](action-contract.json): the boundaries an implementation must enforce.
- [Agent profile](agent-profile.json): per-agent binding to shared controls, grant references, evaluations and evidence.
- [Authority review](authority-review.json): a hypothetical A2-to-A3 request retained at A2 because decision evidence is incomplete.
- [Evaluation cases](evaluation-cases.json): twenty-two scenarios specifying execution, semantic-evaluation, four-mode and authority-change behavior.
- [Supporting intent contract](ai-dlc-intent.md): the proposed business outcome, scope and acceptance evidence for the account-maintenance feature.

These files are not executable policies or executed tests.
